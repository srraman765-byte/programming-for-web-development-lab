# P12 - Portfolio Projects Grid Using Advanced CSS Grid

## Aim
To create a portfolio projects webpage using advanced CSS Grid properties.

## Description
This practical demonstrates advanced CSS Grid techniques to display portfolio project cards in different sizes and arrangements. The featured project occupies two columns and two rows, while other projects are displayed in a grid layout.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

## CSS Grid Properties Used
- `display: grid`
- `grid-template-columns`
- `grid-auto-rows`
- `grid-column: span 2`
- `grid-row: span 2`
- `gap`

## Features
- Professional portfolio header and navigation.
- Six project cards.
- Featured FLONIQ AI project with larger grid area.
- Hover animation on project cards.
- Responsive desktop, tablet and mobile layouts.
- About and Contact sections.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `P12/index.html`.
3. Run using Live Server or a local web server.
4. Resize the browser to test responsive behaviour.
