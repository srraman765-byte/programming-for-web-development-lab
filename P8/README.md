# P8 - Sticky Navbar and Card Overlay Using CSS Positioning

## Aim
To create a webpage using CSS positioning properties such as sticky, relative and absolute.

## Description
This practical demonstrates how CSS positioning can be used to create a sticky navigation bar and an overlay effect on a project card.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## CSS Concepts Used
- position: sticky
- position: relative
- position: absolute
- z-index
- top, bottom and left properties

## Features
- Sticky navigation bar that remains at the top while scrolling
- Project card with an image overlay
- Navigation links to different sections
- Styled portfolio layout

## How to Run
1. Open the P8 folder.
2. Open index.html in a web browser.
3. Scroll the webpage to test the sticky navigation bar.
4. View the project card to see the overlay effect.
