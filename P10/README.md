# P10 - Portfolio Header and Footer Using Advanced Flexbox

## Aim
To create a responsive portfolio webpage with a professional header and footer using advanced CSS Flexbox properties.

## Description
This practical demonstrates the use of CSS Flexbox to arrange elements in the portfolio header and footer. The layout adjusts to different screen sizes using responsive CSS techniques.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

## Flexbox Properties Used
- `display: flex`
- `justify-content`
- `align-items`
- `flex-wrap`
- `flex-direction`
- `gap`
- `flex-basis`

## Features
- Portfolio header with logo, navigation links and Hire Me button.
- Flexbox-based alignment of header elements.
- Footer with brand information, navigation and social links.
- Responsive layout for mobile screens.
- Media queries for smaller devices.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `P10/index.html`.
3. Run the webpage using Live Server or a local web server.
4. Resize the browser to test the responsive layout.
