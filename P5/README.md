# P5 - Semantic Bio Page

## Aim
To create a personal biography webpage using semantic HTML5 elements.

## Description
This practical demonstrates the use of semantic HTML5 elements to create a structured personal biography webpage.

## Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## Semantic HTML Elements Used
- header
- nav
- main
- section
- article
- footer

## Features
- Personal introduction
- Education details
- Skills list
- Navigation links to different sections

## How to Run
1. Open the P5 folder.
2. Open index.html in a web browser.
3. Click the navigation links to visit different sections.
