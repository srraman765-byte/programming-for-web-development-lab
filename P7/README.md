# P7 - Design Tokens and Typography System in CSS

## Aim
To create a reusable design token system and typography system using CSS.

## Description
This practical demonstrates CSS custom properties (variables) for managing colors, typography, spacing, border radius and shadows consistently across a portfolio webpage.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## CSS Concepts Used
- CSS custom properties
- `:root` selector
- Color variables
- Typography variables
- Spacing variables
- `var()` function
- Font family and font sizes
- Border radius and box shadow

## Features
- Consistent color scheme
- Reusable CSS design tokens
- Structured typography system
- Styled navigation bar and content cards
- Consistent spacing and visual appearance

## How to Run
1. Open the P7 folder.
2. Open `index.html` in a web browser.
3. The browser will automatically load `style.css`.
