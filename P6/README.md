# P6 - Full Portfolio Page Structure in Semantic HTML

## Aim
To create a complete personal portfolio webpage using semantic HTML5 elements.

## Description
This practical demonstrates how to structure a professional personal portfolio webpage using semantic HTML5 elements.

## Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## Semantic HTML Elements Used
- `header`
- `nav`
- `main`
- `section`
- `article`
- `aside`
- `footer`

## Sections Included
- Home
- About Me
- Education
- Skills
- Projects
- Contact
- Career Goal

## Features
- Complete personal portfolio structure
- Navigation links to different sections
- Education and skills information
- Personal project details
- Contact information

## How to Run
1. Open the P6 folder.
2. Open `index.html` in a web browser.
3. Click the navigation links to visit different sections.
