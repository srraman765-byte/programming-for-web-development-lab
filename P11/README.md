# P11 - Newspaper Layout Using CSS Grid

## Aim
To create a newspaper-style webpage with a three-column layout using CSS Grid.

## Description
This practical demonstrates CSS Grid to create a newspaper layout containing a left sidebar, a main news section and a right sidebar. A responsive media query changes the layout into a single column on smaller screens.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

## CSS Grid Properties Used
- `display: grid`
- `grid-template-columns`
- `gap`
- `margin`
- `padding`

## Features
- Newspaper-style header and navigation bar.
- Three-column desktop layout.
- Latest News sidebar.
- Main news article section.
- Editor's Picks sidebar.
- Responsive single-column mobile layout.
- Styled footer.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `P11/index.html`.
3. Run using Live Server or a local web server.
4. Resize the browser to test responsive behaviour.
