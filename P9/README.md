# P9 - Responsive Navbar and Card Grid Using Flexbox

## Aim
To create a responsive navigation bar and card grid layout using CSS Flexbox.

## Description
This practical demonstrates the use of CSS Flexbox and media queries to create a responsive portfolio webpage that adapts to desktop and mobile screen sizes.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## CSS Concepts Used
- display: flex
- justify-content
- align-items
- flex-wrap
- flex-direction
- gap
- flex-basis
- Media queries

## Features
- Responsive navigation bar
- Flexible skills card grid
- Responsive project card grid
- Mobile-friendly layout
- Consistent spacing and styling

## Testing
- Tested on desktop screen.
- Tested on mobile screen using Chrome Device Toolbar.
- Verified vertical navbar and card layout on mobile.

## How to Run
1. Open the P9 folder.
2. Open index.html in a web browser.
3. Resize the browser or use Chrome Device Toolbar to test responsiveness.
