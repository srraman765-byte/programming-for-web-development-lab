# P13 - Choosing Between Flexbox and CSS Grid

## Aim
To understand and compare Flexbox and CSS Grid for creating responsive web layouts.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid

## Description
This practical demonstrates two CSS layout systems using the same set of content cards.

### Flexbox
- Used for one-dimensional layouts.
- Arranges items in a row or column.
- Useful for navigation bars and aligning elements.
- Uses `display: flex`.

### CSS Grid
- Used for two-dimensional layouts.
- Arranges items in rows and columns.
- Useful for complex page layouts.
- Uses `display: grid`.

## Responsive Design
Media queries are used to adjust the Grid layout for tablet and mobile screens.

## Conclusion
Flexbox is suitable for one-dimensional layouts, while CSS Grid is suitable for two-dimensional layouts. Both can be combined to create responsive websites.
